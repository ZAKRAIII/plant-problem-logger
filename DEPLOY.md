# Panduan Deploy Gratis Multi-User (GitHub Pages + Supabase)

Panduan ini menjelaskan cara men-deploy **Plant Problem Logger** secara gratis agar bisa diakses bersamaan oleh banyak pengguna (Operator, Teknisi, Supervisor) dari HP maupun PC melalui internet.

---

## Arsitektur
- **Frontend (`public/`):** Di-host gratis di **GitHub Pages** (`https://<username>.github.io/<nama-repo>/`).
- **Database:** **Supabase PostgreSQL** (Free Tier: 500 MB).
- **Penyimpanan Foto & Video:** **Supabase Storage** (Free Tier: 1 GB).

---

## Langkah 1: Buat Project di Supabase (Gratis)
1. Buka [supabase.com](https://supabase.com/) lalu daftar / login menggunakan akun GitHub Anda.
2. Klik **New Project**:
   - **Name:** `plant-problem-logger`
   - **Database Password:** buat password yang kuat (simpan baik-baik).
   - **Region:** pilih **Singapore (`ap-southeast-1`)** agar latensi paling cepat dari Indonesia.
3. Tunggu ±1–2 menit hingga project selesai dibuat.

## Langkah 2: Buat Tabel Database di Supabase
1. Di dashboard Supabase, buka menu **SQL Editor** → klik **New query**.
2. Jalankan SQL berikut untuk membuat tabel `equipments` dan `problem_logs`:

```sql
-- 1. Tabel Master Equipment
create table if not exists public.equipments (
  id bigint generated by default as identity primary key,
  kode_mesin text not null,
  jenis_equipment text not null,
  line text not null,
  is_active boolean not null default true,
  created_at timestamptz default now()
);

-- 2. Tabel Log Problem
create table if not exists public.problem_logs (
  id bigint generated by default as identity primary key,
  tanggal_problem_masuk date not null,
  jam_problem_masuk text not null,
  line text not null,
  kode text not null,
  nama_equipment text not null,
  kategori text not null,
  deskripsi_kendala text not null,
  status text not null,
  tanggal_problem_selesai text default '',
  jam_problem_selesai text default '',
  durasi_menit integer,
  shift text default '',
  pelapor text default '',
  pic_teknisi text default '',
  deskripsi_kegiatan_perbaikan text default '',
  lampiran_report jsonb not null default '[]'::jsonb,
  lampiran_resolve jsonb not null default '[]'::jsonb,
  created_at timestamptz default now()
);

-- 3. Aktifkan RLS & izinkan akses publik (karena mode saat ini tanpa login)
alter table public.equipments enable row level security;
alter table public.problem_logs enable row level security;

create policy "Allow all equipments" on public.equipments
  for all using (true) with check (true);

create policy "Allow all problem_logs" on public.problem_logs
  for all using (true) with check (true);

-- 4. Berikan hak akses tabel & sequence ke role anon
grant usage on schema public to anon, authenticated;
grant all on table public.equipments to anon, authenticated;
grant all on table public.problem_logs to anon, authenticated;
grant usage, select on all sequences in schema public to anon, authenticated;
```

## Langkah 3: Buat Storage Bucket untuk Foto & Video
1. Buka menu **Storage** di Supabase → klik **New bucket**.
2. Isi:
   - **Name:** `plant-media`
   - **Public bucket:** centang **ON** (agar foto/video bisa langsung tampil di web).
3. Klik **Create bucket**.
4. Masuk ke bucket `plant-media` → tab **Policies** → klik **New policy** → **For full customization**:
   - Izinkan operasi `SELECT`, `INSERT`, `UPDATE`, `DELETE` untuk role `anon` (`true`) agar pengguna bisa mengunggah dan melihat dokumentasi foto/video.

---

## Langkah 4: Ambil URL & API Key Supabase
Pada tampilan Supabase terbaru, menunya terpisah menjadi dua bagian di **Project Settings** (ikon roda gigi di kiri bawah):
1. **Ambil Project URL:**
   - Di sidebar kiri, klik **Data API** (di bawah bagian *INTEGRATIONS*) — atau lihat **Project ID** di menu **General** (`https://<Project-ID>.supabase.co`).
   - Salin **Project URL** (contoh: `https://xxxxxxxxxxxx.supabase.co`).
2. **Ambil API Key (`anon` / `Publishable`):**
   - Di sidebar kiri, klik **API Keys** (di bawah bagian *CONFIGURATION*).
   - Salin **Publishable key** (`sb_publishable_...`), atau buka tab **Legacy anon, service_role API keys** lalu salin key **`anon` (`public`)**.
   - *(Jangan pernah menyalin atau membagikan `service_role` / `secret` key ke kode frontend.)*

## Langkah 5: Sesuaikan Frontend untuk Mode Supabase
Karena GitHub Pages hanya melayani file statis di folder `public/`:
1. Pastikan seluruh panggilan API di `public/app.js` (`/api/bootstrap`, `/api/logs`, `/api/equipments`, `/api/upload`) diarahkan ke Supabase REST API & Storage API menggunakan `Project URL` dan `anon public key` di atas.
2. Untuk fitur **Export CSV**, generate file CSV langsung di browser dari data `state.logs` menggunakan `Blob` + `URL.createObjectURL`.

*(Jika Anda mau, saya bisa langsung buatkan file konfigurasi Supabase + update `app.js` agar otomatis mendukung mode lokal maupun GitHub Pages.)*

## Langkah 7: Aktifkan GitHub Pages (Auto-Deploy)
1. Buat file `.github/workflows/deploy.yml` di repository Anda untuk mempublikasikan folder `public/` ke GitHub Pages:

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: ["main"]

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
      - name: Setup Pages
        uses: actions/configure-pages@v5
      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: "public"
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

2. Di halaman repository GitHub Anda, buka **Settings → Pages**.
3. Pada bagian **Build and deployment → Source**, pilih **GitHub Actions**.
4. Setiap kali Anda `git push` ke branch `main`, aplikasi otomatis ter-deploy dan dapat diakses melalui:
   ```text
   https://<USERNAME_ANDA>.github.io/plant-problem-logger/
   ```

## Catatan Keamanan & Batas Free Tier
- **Batas Supabase Free Tier:** 500 MB database & 1 GB storage file. Untuk penggunaan jangka panjang dengan banyak video, kompres video singkat atau bersihkan lampiran lama secara berkala.
- **Auto-Pause:** Supabase Free Tier akan *pause* otomatis jika **tidak ada akses sama sekali selama 7 hari**, dan bisa diaktifkan kembali lewat tombol *Restore* di dashboard Supabase.
- **Hak Akses:** Karena saat ini menggunakan mode tanpa login (hanya input nama di awal sesi), simpan link aplikasi hanya untuk tim internal *plant*. Jika ke depan butuh login per akun, Supabase Auth dapat langsung diaktifkan pada tabel yang sama.
